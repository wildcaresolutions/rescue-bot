Quick Start

Add this code to your website, just before the closing </body> tag:

<!-- WildCare Chat Widget -->
<script>
   window.WildCareChat = {
     baseUrl: 'https://wildcare.bluesnoop.com',	
     autoOpen: false,
     agentName: 'Wildcare Help Assistant',
     buttonLabel: 'Need Help?',
   };
 </script>
<script src="https://wildcare.bluesnoop.com/widget.js"></script>

The widget will appear as a floating button in the bottom-right corner.

Configuration Options

Customize the widget by setting window.WildCareChat before loading the script:

<script>
   window.WildCareChat = {
     autoOpen: false,
     agentName: 'Wildlife Help',
     buttonLabel: 'Need Help?',
   };
 </script>
 <script src="https://wildcare.bluesnoop.com/widget.js"></script>
Testing/Staging: Set baseUrl: '/' to use same-origin API calls (useful for local development or staging environments).

All Options

Option Type Default Description
baseUrl string null (same origin) Root URL for API calls. Use 'https://wildcare.bluesnoop.com' for cross-origin embedding, or '/' for same-origin (testing/staging).
autoOpen boolean true Automatically open the chat pane when the page loads
agentName string 'Wildlife Rescue Assistant' Name shown in the chat header
buttonLabel string 'Chat' Text on the floating button
welcomeMessage string 'Hello! I'm here to help...' Initial message shown when chat opens. Set to empty string to disable.
theme object {...} Custom colors (see Theming section below)
width string '90%' Widget width (CSS value)
maxWidth string '600px' Maximum widget width
height string 'auto' Widget height (CSS value)
maxHeight string '80vh' Maximum widget height
minWidth string '320px' Minimum widget width (for resizing)
minHeight string '400px' Minimum widget height (for resizing)
resizable boolean true Allow users to drag-resize the widget (desktop only)
buttonPosition object null CSS position overrides for the floating button, e.g. { left: '20px', right: 'auto', bottom: '100px' }
panePosition object null CSS position overrides for the chat window container, e.g. { left: '20px', right: 'auto', bottom: '100px' }
Resizing: When resizable: true (default), users can drag the bottom-right corner to resize the widget. This only works on desktop browsers.

Positioning

By default the widget button appears in the bottom-right corner. Use buttonPosition and panePosition to move it — no CSS overrides needed:

Move to Bottom-Left

<script>
  window.WildCareChat = {
    baseUrl: 'https://wildcare.bluesnoop.com',
    buttonPosition: { right: 'auto', left: '20px' },
    panePosition:   { right: 'auto', left: '20px' },
  };
</script>

Move Higher (Avoid Overlapping Another Button)

<script>
  window.WildCareChat = {
    baseUrl: 'https://wildcare.bluesnoop.com',
    buttonPosition: { bottom: '100px' },
    panePosition:   { bottom: '100px' },
  };
</script>
Tip: Position properties map directly to CSS — you can use any combination of top, bottom, left, right with CSS values.

Theming

Match the widget to your brand colors using the theme object:

<script>
  window.WildCareChat = {
    theme: {
      primaryColor: '#78a12e',    // Button, links, accents
      secondaryColor: '#004863',  // Header background
      textColor: '#333333',       // Main text color
    }
  };
</script>

Theme Properties

Property Default Used For
primaryColor #78a12e Floating button, send button, user message bubbles, links, focus states
secondaryColor #004863 Header gradient (combined with primaryColor), bold text emphasis
textColor #333333 Primary text in assistant messages and input field
Tip: The header uses a gradient from secondaryColor to primaryColor. For best results, choose colors that complement each other.

Advanced: Custom CSS

The widget renders inside a Shadow DOM, which means host-page CSS cannot penetrate the shadow boundary and will not affect widget elements. To customize appearance, use the admin Custom CSS field (Playbook → Custom CSS) — styles entered there are injected directly inside the shadow root. All widget elements use the rbot-widget- prefix:

/* Example: Make the button circular */
.rbot-widget-button {
  width: 60px;
  height: 60px;
  padding: 0;
  border-radius: 50%;
}

/* Example: Custom chat pane width */
.rbot-widget-pane {
  max-width: 400px;
}

/* Example: Different mobile behavior */
@media (max-width: 768px) {
  .rbot-widget-pane {
    border-radius: 0;
  }
}

Behavior Notes

Session Persistence

The widget saves the conversation session in a cookie (wildcare_session_id). Users returning to your site will see their previous conversation.

Mobile Experience

On screens narrower than 768px, the chat pane expands to full screen for easier use on phones.

Feedback Collection

Each assistant response shows thumbs up/down buttons. This feedback helps improve the AI responses. Feedback from the embedded widget is tagged as coming from public users (not testers).

Note: The widget requires a connection to wildcare.bluesnoop.com. It won't work offline or if your Content Security Policy blocks external scripts.

      welcomeMessage: 'Hi! Describe the animal you found and I will help you.',
      theme: {
        primaryColor: '#2e7d32',
        secondaryColor: '#1b5e20',
      }
    };
  </script>
  <script src="https://wildcare.bluesnoop.com/widget.js"></script>
</body>
